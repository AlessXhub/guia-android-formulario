

## Abrir y ejecutar

1. Abrir la carpeta del proyecto en Android Studio.
2. Esperar a que Gradle termine la sincronización.
3. Seleccionar un emulador o dispositivo con Android 8.0 o superior.
4. Ejecutar el módulo `app`.
